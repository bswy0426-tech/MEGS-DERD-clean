# Featurize runtime reference list for MEGS-DERD.
#
# Do not blindly run `pip install -r requirements-featurize.txt` on a working
# Featurize image. The server usually already has PyTorch/CUDA installed, and
# a full reinstall may replace torch or NumPy. Use this file as a checklist and
# install only the missing packages reported by Python.
#
# If you need a one-shot repair, prefer:
#   bash scripts/install_featurize_deps.sh
#
# Or install with constraints:
#   python -m pip install -c constraints-featurize.txt -r requirements-featurize.txt
#
# Keep NumPy below 2 because the preinstalled PyTorch/CUDA stack may be
# compiled against NumPy 1.x.
